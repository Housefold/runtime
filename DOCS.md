# Housefold Runtime

This app is the local Housefold process foundation. It starts without the optional Bridge, feature modules, or cloud services. It keeps a long-lived Home Assistant WebSocket session, builds a candidate state map from `get_states` and buffered `state_changed` events, then publishes synchronized state as an in-memory generation. It does not execute HA service calls.

The Supervisor watchdog uses the app's read-only `/healthz` endpoint. The app does not publish a host port or provide a control API. Use Home Assistant's app controls and logs to inspect, stop, start, or recover the process. HA session phase/status and state freshness are separate from Runtime process health. The ingress page shows coarse metadata only; it never exposes entity IDs, values, attributes, or events. If Home Assistant Core is unavailable, use the HAOS host console's `ha apps` commands to inspect the app and its logs.

The app requests `homeassistant_api` access and uses the runtime-provided `SUPERVISOR_TOKEN` for the approved read-only state operations. The token and household state are not persisted or logged. HA loss immediately marks the published state generation stale; reconnect builds and reconciles a new candidate generation. The freshness boundary and its public API limitations are recorded in [ADR-003](docs/adr/003-ha-state-cache-and-reconnection.md). The read-only local status page is served through authenticated HA ingress under [ADR-005](docs/adr/005-local-operator-status.md); Supervisor controls/logs and the HAOS host console remain the recovery paths.

Runtime v1 productization is in progress under [PRODUCTIZATION.md](docs/agent/PRODUCTIZATION.md). The App uses empty options, native Supervisor authentication, boot/watchdog/ingress conventions and cold backups. Its startup provisions private `/data/housefold` then runs as UID/GID 10001; invalid storage is preserved and reports recovery required. `panel_admin` hides the panel for non-admins; full BIOS server-side authorization is pending V1P03. Do not install this development foundation on a live household or treat historical library/HAOS evidence as Runtime v1 acceptance.
