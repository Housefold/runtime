# V1P07 — bounded App logs, diagnostic projection and durable admin audit

Entering HEAD: 4bdb779. Final implementation: cohesive V1P07 commit with this record.

Production behavior:

- Runtime's composition creates a privacy-allowlisted structured JSON App stdout
  handler and shares its bounded event ring with BIOS. Managed module IPC logs use
  launcher-owned module/version/generation attribution and a finite code enum.
  Synthetic reference module emits actual ready/completion records for acceptance.
- At most 64 module events/second globally, 128 retained records, 64 queued output
  frames and 1KiB/frame. Producers never wait on stdout. A close-on-exec duplicate
  of the inherited App output pipe is nonblocking and writes have 100ms deadlines.
  Output backpressure/failures/drop counts are visible; shutdown cancels/joins the
  one writer. No credentials/free-form household/error payload enters either log
  stream or BIOS ring. Normal HA App logs remain the full live stream.
- BIOS shows structured events and durable administrative audit to verified admins.
  Downloadable diagnostics use explicit coarse DTO fields rather than serializing
  evolving internal objects: build/source/Go/architecture, goroutines, HA metadata,
  module lifecycle/usage/limits, storage/Bridge/catalog and log/audit counts.
  Excludes user IDs/names, raw errors/paths, household state, bindings, log contents,
  form approvals and network declarations.
- Estate owns checksummed atomic private audit.json, at most 256 records and
  monotonic sequence, UTC time, verified HA user ID, finite operation/subject/outcome.
  Durable intent precedes a mutation; result commit follows. Commit failure blocks
  ordinary operations. Restart marks prior requested operations interrupted and
  never replays them. Snapshot ownership, overflow, corruption and uncertain commit
  are fenced. An explicit metadata marker distinguishes one-time existing-estate
  migration from missing/corrupt initialized audit; no silent recreation.
- Audit participates in I/O gating/storage accounting/cold-backup checkpoints.
  Stopped estate cannot write after its checkpoint. Confirmed factory reset may
  escape an unavailable/unwritable audit and intentionally deletes its journal
  with all owned data; it never recreates that journal before normal App restart.
